Frequently Asked Questions

How does MelodyMind AI generate music?

MelodyMind AI uses recurrent neural networks built with LSTM layers. By analyzing a dataset of MIDI files, the model learns transitions between notes and chords (which combinations follow others). When composing, we feed the model a seed melody, and it predicts the next note. This output is appended to the seed, and the window slides forward to predict the next note.

What are notes and chords in this model's vocabulary?

We use the music21 toolkit to read MIDI files. Single notes are stored as pitch strings (e.g., E4). Chords are represented by combining notes with dot separators (e.g., C4.E4.G4). The model treats each chord shape and note pitch as a unique token in its dictionary.

What does "Temperature" do during music generation?

Temperature controls the creativity of the music generation. A lower temperature (e.g., 0.2) forces the model to pick only the absolute most likely notes, making the output structured but potentially repetitive. A higher temperature (e.g., 1.5) scales the probability distribution, making unlikely notes more probable, resulting in wild, creative, and experimental melodies.

How do I play the music directly in my browser?

MIDI files contain musical command instructions but no actual sound. To play them in a web browser, the Flask backend uses the pretty_midi library to synthesize the MIDI notes into wave data using standard sine synthesis. This WAV file is served directly to the frontend, where WaveSurfer.js renders its waveform and plays the audio dynamically.
