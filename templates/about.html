01 MIDI Preprocessing Pipeline

Raw MIDI files are not waveforms; they are binary event files containing instructions (note on/off, pitch, velocity, timing). To train an AI, we need to extract and structure this information:

  • Parsing with music21: We load and flatten MIDI files, identifying individual instrument paths and extracting chronological note and chord event streams.
  • Note vs Chord Encoding: Single notes are parsed as simple pitch names (e.g. C4). Chords are sorted by note frequency and represented as dots connecting pitches (e.g. C4.E4.G4) to ensure consistent vocabulary tokenization.
  • Sequence Segmentation: The continuous stream is segmented into training windows of length 100. Each input sequence predicts the 101st note/chord, capturing long-term melodic contexts.

02 Neural Network Architecture

Our model is a Recurrent Neural Network (RNN) designed for sequential data processing. Standard feedforward networks assume inputs are independent, whereas musical structures depend entirely on historical sequences.

  • Double LSTM Blocks (512 Nodes): Long Short-Term Memory cells resolve the "vanishing gradient" problem of standard RNNs. They maintain cell states over long windows, remembering motifs across the 100-note window.
  • Dropout Regularization (30%): Dropout blocks randomly deactivate neurons during training. This prevents overfitting, forcing the network to learn robust global relationships instead of memorizing specific files.
  • Categorical Crossentropy loss: Compares predictions to actual notes using multi-class probabilities, optimizing accuracy using the Adam optimizer.

03 Deployment & Setup Instructions

Repository Structure

Prepare a GitHub repository named CodeAlpha_Music_Generation_AI. Ensure directory structures are populated. Push code to main branch.

git init
git add .
git commit -m "Initialize MelodyMind AI"
git remote add origin <repo_url>
git branch -M main
git push -u origin main

Render Deployment

Deploy instantly as a Web Service on Render:

  • Connect GitHub repo to Render Dashboard.
  • Select **Python** environment. Build Command: pip install -r requirements.txt
  • Start Command: gunicorn app:app
  • Render will auto-detect runtime.txt and deploy with Python 3.11.
